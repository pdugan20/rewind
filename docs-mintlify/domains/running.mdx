## Overview

The Running domain tracks running activities, including distance, pace, elevation, splits, gear, and personal records. The history through August 2026 came from Strava; new runs come from Apple Health.

An iPhone app sends each run to Rewind shortly after it lands in Apple Health, with its route and heart rate. Rewind calculates mile splits, elevation gain, and best efforts from the route, so these runs appear in the same endpoints as the Strava history. Browse every endpoint in the [API reference](/api-reference/running/lifetime-running-statistics).

## Charts

Several endpoints return chart-ready series for plotting: cumulative distance, pace trend, time-of-day distribution, and elevation gain over time.

## Filtering

The activities endpoint supports filtering by:

- `year`: filter to a specific year.
- `type`: workout type (default, race, long_run, etc.).
- `city`: filter by city name.
- `min_distance` / `max_distance`: distance range in miles.
- `sort`: sort field (date, distance, pace, elevation).
- `order`: asc or desc.
- Standard date filters (`date`, `from`, `to`).

## Year in review

For a per-year breakdown, use [GET /running/stats/years/:year](/api-reference/running/single-year-summary). It returns year-specific stats such as total runs, distance, elevation, and pace for the requested year.
